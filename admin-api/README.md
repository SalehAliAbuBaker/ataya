# حذف الحساب نهائيًا من داخل سجل العطايا

**حالة التنفيذ (29 أكتوبر 2026):** تمت كتابة خدمة إدارية مبدئية في `worker.js`،
لكنها لم تُنشر على Cloudflare ولم تُربط بالتطبيق؛ لا يُحذف أي حساب حتى ذلك الحين.

## الفرق بين الإجراءات الثلاثة

- **تعديل الصلاحيات:** تغيير صلاحيات مستخدم موجود من داخل العطايا.
- **حذف الصلاحيات:** إزالة سجل الصلاحيات في قاعدة Ataya Data فقط؛ لا يحذف حساب الدخول.
- **حذف الحساب نهائيًا:** إزالة حساب المستخدم من Firebase Authentication
  ثم إزالة سجل صلاحياته، مع عدم المساس ببيانات المستفيدين والعطايا وحركات الصرف.

## لماذا نحتاج خدمة على الخادم؟

تطبيق GitHub Pages ثابت، وFirebase Web SDK لا يعطي المدير صلاحية حذف حسابات الآخرين
دون بيانات دخول المستخدم المستهدف. الإدارة الآمنة دون كلمة مرور المستخدم تتطلب
اعتماد خدمة مُدارًا في الخادم. يمكن تشغيل Cloudflare Workers مع Firebase Spark
بدون ترقية Firebase، تبعًا لحدود الاستخدام المتاحة في كل خدمة.

## متطلبات الأمان قبل النشر

1. مراجعة قواعد Firebase Realtime Database في مشروع `atayadata-e5810` والتحقق من
   أن القراءة والكتابة والحذف مقيدة بحسب الحساب والصلاحيات. إخفاء الأزرار ليس حماية كافية.
2. إنشاء حساب خدمة مؤهّل لإدارة Firebase Authentication وقراءة وحذف
   `atp_v2/permissions` فقط عند الحاجة. يفضّل مبدأ أقل الصلاحيات.
3. حفظ اعتماد حساب الخدمة JSON **كسر في Cloudflare Worker فقط** باسم
   `FIREBASE_SERVICE_ACCOUNT_JSON`. لا تضعه في ملفات GitHub أو في المتصفح،
   ولا ترسله ضمن المحادثة.
4. ضبط `ALLOWED_ORIGIN` على `https://salehaliabubaker.github.io`.
5. تجربة الخدمة على حساب تجريبي فقط. اختبر أن غير المدير ممنوع،
   وأن المدير لا يستطيع حذف حسابه الحالي أو آخر حساب مدير.

## نشر الخدمة على Cloudflare عند توفر اعتماد الخادم

داخل مجلد `admin-api` يمكن نشر الخدمة باستخدام Cloudflare Wrangler:
```bash
npx wrangler deploy
npx wrangler secret put FIREBASE_SERVICE_ACCOUNT_JSON
```
الإعدادات الأساسية في `wrangler.toml`. بعد نجاح النشر يجب ربط العنوان
العام للخدمة (ليس الاعتماد السري) في ثابت `ACCOUNT_DELETE_API` بالملف
`trial/index.html`، ثم إعادة اختبار إجراءات الحذف.

لا تضغط «حذف الحساب نهائيًا» للاختبار على حساب حقيقي. الحذف غير قابل للتراجع
ولا ينظّف نسخة البيانات المحلية على أجهزة أخرى.

**تنبيه:** هذا تنفيذ أولي، وقد جرى فحص صياغة JavaScript فقط. لم يتم
اختبار الاتصال الحقيقي بـ Firebase Authentication وRealtime Database.
